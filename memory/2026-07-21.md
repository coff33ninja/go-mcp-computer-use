## Architecture Decisions
- Embedding table is owned by Go, not in the Gorgonia graph (no Gather op available)
- Tokens are looked up via `lookupEmbed()` in Go, then fed as float64 input to the graph
- Only batch-size-1 is supported (sufficient for inference, batch training can iterate)
- `allLearnableNodes()` collects graph nodes for Save/Load; embedTable saved separately
